# ASUFC Financial Management
Development prototype. Do not upload real records or secrets.

Copy `.env.example` to `.env`, replace both passwords with random values, and run `docker compose up --build`. Open http://localhost:8000/docs and authenticate with configured staff credentials. API only at this milestone; not production-ready. Run unit tests with `docker compose run --rm api python -m pytest`.

See docs/architecture.md and PROGRESS.md.
