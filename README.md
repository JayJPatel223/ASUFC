# ASUFC Financial Management & Spending Tracker

Course project for COMP 2663 at Acadia University. Internal staff-only financial management system; no student food-access records.

## Development roadmap
1. Architecture, authentication and database foundation.
2. Funding, program budgets, expenses and split allocations.
3. Dashboard, audit history and reporting.
4. Excel migration and academic-year carry-forward.
5. Reviewed AI assistance.

Development uses fictional data only. Do not upload actual financial records, receipts or secrets to this public repository.

Initial implementation is under development; not suitable for production use.
